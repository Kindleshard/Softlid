# BlinkBuddy

Eye care that lives in the Windows tray: blink and break reminders, a screen filter, a reading strip, a focus
timer and more.

- `csharp/` — the original version (C#, .NET Framework 4.8). Complete; the reference for the rewrite.
- `cpp/` — the rewrite in C++ and Direct2D, for a much smaller memory footprint. See `cpp/docs/PLAN.md`.
